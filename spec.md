# Project Specification: Testimonials Collection Tool

## 1. Project Overview
Build a 4-layer testimonials collection and display system. The tool will allow users to submit testimonials, use the Gemini API to intelligently process the text (auto-tagging and quote extraction), store data and images in the Google Workspace ecosystem (Sheets and Drive), notify admins via chat, provide an admin dashboard for moderation, and output an embeddable "Wall of Love" for public display.

## 2. Architecture & Tech Stack (Recommended)
*   **Database:** Google Sheets
*   **File Storage:** Google Drive (for headshots)
*   **AI Integration:** Gemini API
*   **Notifications:** Google Chat Webhook (or Slack Webhook)
*   **Frontend:** HTML/CSS/JS (Served via Google Apps Script Web App or a lightweight frontend framework)

## 3. Data Schema (Google Sheet Columns)
The primary database should be a Google Sheet with the following columns:
1.  `Timestamp` (Auto-generated)
2.  `Name` (String, Required)
3.  `Email` (String, Required - Private)
4.  `Organization` (String, Optional)
5.  `Rating` (Integer 1-5, Required)
6.  `Testimonial` (Text, Required)
7.  `Headshot_URL` (String, Drive File Link)
8.  `Extracted_Quote` (Text, Auto-generated by Gemini)
9.  `Tags` (Comma-separated string, Auto-generated by Gemini)
10. `Status` (Enum: 'Pending', 'Approved', 'Rejected' - Default: 'Pending')

## 4. Layer Details & Feature Requirements

### Layer 1: Submission Form
*   **UI Components:**
    *   Form fields: Name, Email, Organization (optional), Rating (1-5 stars/dropdown), Testimonial (textarea), Headshot Image (file upload).
*   **Backend Processing:**
    *   **Image Handling:** Check the uploaded image file size. If it exceeds a reasonable threshold (e.g., 500KB), resize/compress the image before saving it to a designated Google Drive folder. Set the Drive file permissions so the image is viewable by anyone with the link (for the Wall of Love).
    *   **Data Saving:** Append the raw form data and the new Drive URL to the Google Sheet.
    *   **Trigger AI:** Pass the submitted testimonial text to the Gemini API pipeline.

### Layer 2: Gemini API Integration (The AI Pipeline)
When a new testimonial is submitted, trigger a prompt to the Gemini API with the `Testimonial` text to perform two tasks:
1.  **Auto-tagging by topic:** Scan the text and categorize it based on mentioned aspects (e.g., "beginner-friendly", "time-saving", "Google Sheets", "AI tools", "customer support"). Return a comma-separated list of tags.
2.  **Best Quote Extraction:** Analyze the long-form text and extract the single strongest, most impactful sentence or phrase suitable for large text on a sales page. 
*   **Output:** Update the corresponding Google Sheet row with the `Extracted_Quote` and `Tags`.

### Layer 3: Chat Notification
*   **Action:** Upon successful database insertion and AI processing, trigger an HTTP POST request to a Chat Webhook (e.g., Google Chat space).
*   **Payload:** Send a formatted card or message containing:
    *   Submitter Name
    *   Rating
    *   The `Extracted_Quote`
    *   A link to the Admin Dashboard to approve/reject.

### Layer 4: Admin Dashboard
*   **UI Components:**
    *   **Analytics Overview:** Visual charts (e.g., total testimonials submitted, average rating, count of testimonials by tag).
    *   **Moderation Queue:** A data table listing all testimonials, prioritized by 'Pending' status.
*   **Functionality:**
    *   Admins can view all data (including the private Email).
    *   Admins can edit the Gemini-generated `Extracted_Quote` or `Tags` if they need manual refinement.
    *   Admins can toggle the `Status` of a testimonial (Approve or Reject), which updates the Google Sheet instantly.

### Layer 5: Wall of Love (Public Display)
*   **UI Components:**
    *   An embeddable UI block (e.g., an `iframe` or a JS snippet) meant to be placed on external sales pages.
    *   **Filter Bar:** A row of interactive buttons at the top, populated dynamically by the unique `Tags` of *approved* testimonials.
    *   **Testimonial Cards:** A grid or masonry layout displaying the testimonials.
*   **Content Rules:**
    *   ONLY query and display rows where `Status` = 'Approved'.
    *   Display: Name, Headshot Image, Organization, Rating, and the `Extracted_Quote` (or full Testimonial). 
    *   **CRITICAL:** NEVER expose the submitter's `Email` address in the frontend payload or HTML.
*   **Interactivity:** Clicking a filter tag should instantly filter the displayed testimonial cards to only those containing that tag.

## 5. Development Milestones for anti-gravity
1.  **Setup & Auth:** Initialize the Google Sheet, Drive folder, and API connections (Gemini, Chat Webhook).
2.  **Backend Core:** Create the submission endpoint, image resizing logic, and database insertion.
3.  **AI Logic:** Write and test the Gemini prompts for extraction and tagging; hook it into the submission flow.
4.  **Admin UI:** Build the dashboard for moderation and basic chart rendering.
5.  **Frontend Public UI:** Build the Wall of Love with dynamic tag filtering and secure data fetching (excluding emails).
