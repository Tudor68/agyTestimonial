# TestimonialFlow (PraisePulse) - Testimonial Hub

An end-to-end, multi-layered testimonials collection and display system built on Google Workspace, powered by the **Google Gemini API**, and styled with the modern **TestimonialFlow** design system.

---

## 1. System Architecture

```
[ Public Form (submit.html) ] ──▶ [ doAction('submit') ] ──▶ [ Drive (Headshot) ]
                                          │
                                          ├─▶ [ Gemini API (Quote + Tags) ]
                                          ├─▶ [ Google Sheet (Append Row) ]
                                          └─▶ [ Google Chat Webhook ]
                                                   │
[ Admin Dashboard (admin.html) ] ◀─── Moderation Link ─┘
         │
         ├── Toggle Status (Approve / Reject)
         └── Edit Gemini Quote / Tags
                  │
[ Wall of Love (wall.html) ] ◀── Fetches Approved Testimonials Only (No emails)
```

### Tech Stack
* **Database:** Google Sheets (`Testimonials` tab)
* **File Storage:** Google Drive (public link sharing for headshots)
* **AI Processing:** Google Gemini API (`gemini-2.5-flash`)
* **Alert Notifications:** Google Chat Webhooks (Cards V2 format)
* **Frontend & Backend Engine:** Google Apps Script Web App (HTML5, Tailwind CSS, Plus Jakarta Sans)

---

## 2. Core Features by Layer

### Layer 1: Public Submission Form (`form.html`)
* **URL:** `?page=form` (Default)
* **Visual Theme:** Light mode, Plus Jakarta Sans, Indigo (`#4F46E5`) & Amber (`#F59E0B`) accents.
* **Interactive Star Rating:** Hover effects and real-time sentiment status text (e.g., *“5.0 • Exceptional!”*).
* **Headshot Upload:** Client-side image resizing and compression (`<canvas>`) before uploading to Google Drive to keep storage lightweight.
* **Form Validation & Privacy:** Character counter (up to 800 chars), explicit marketing permission consent checkbox, and privacy assurance notice.
* **Immediate AI Feedback:** Upon successful submission, displays an instant preview of the Gemini-extracted quote hook and topic tags.

### Layer 2: Gemini API Integration (The AI Pipeline)
* **Model:** `gemini-2.5-flash` via REST endpoint.
* **Quote Extraction:** Scans full testimonial text and isolates the single most punchy sentence suitable for marketing banners and cards.
* **Topic Categorization:** Generates 2–4 relevant topic tags (e.g., `Time-saving`, `AI Tools`, `Customer Support`, `High ROI`).
* **Storage:** Populates the `Extracted_Quote` and `Tags` columns in Google Sheets alongside raw input.

### Layer 3: Real-Time Chat Notification Alert
* **Dispatch:** HTTP POST request sent to the configured `CHAT_WEBHOOK_URL`.
* **Cards V2 UI:** Features the submitter's name, star rating, extracted AI quote, topic tags, and a direct action button linking to the Admin Moderation Dashboard.

### Layer 4: Admin Moderation Dashboard (`admin.html`)
* **URL:** `?page=admin`
* **Real-Time Metrics Bento:** Tracks *Total Testimonials*, *Pending Reviews*, *Approved Reviews*, and *Average Rating*.
* **Filter & Search Bar:** Real-time search by reviewer name, organization, email, quote, or tags, plus status dropdowns (`All`, `Pending`, `Approved`, `Rejected`).
* **One-Click Actions:** Instantly toggle status (`Approve`, `Reject`, `Unpublish`).
* **Inline Editor:** Modal allowing administrators to manually refine or edit the Gemini-generated extracted quote and topic tags.
* **Full Feedback Inspector:** Modal displaying private reviewer email and unedited feedback.

### Layer 5: Embeddable Wall of Love (`wall.html`)
* **URL:** `?page=wall`
* **Card Grid Layout:** Responsive 3-column card grid highlighting reviewer avatars, company roles, ratings, and AI quote callouts.
* **Dynamic Filter Bar:** Automatically extracts and computes count badges for all unique tags from currently *approved* testimonials.
* **Get Embed Code Modal:** Provides a one-click iframe snippet that can be pasted directly into external web pages or CMS platforms.
* **Strict Privacy Guarantee:** Never exposes reviewer email addresses in the HTML or JSON payloads.

## 3. Data Schema (Google Sheet: `Testimonials`)

| Column # | Column Name | Type | Description |
|---|---|---|---|
| **1** | `Timestamp` | DateTime | Submission date and time |
| **2** | `Name` | String | Submitter's full name |
| **3** | `Email` | String | Submitter's email (**Strictly Private**) |
| **4** | `Organization` | String | Company name & title (Optional) |
| **5** | `Rating` | Integer | Rating score (1 to 5) |
| **6** | `Testimonial` | Text | Full testimonial text |
| **7** | `Headshot_URL` | String | Google Drive public thumbnail link |
| **8** | `Extracted_Quote` | Text | High-impact quote generated by Gemini |
| **9** | `Tags` | String | Comma-separated tags generated by Gemini |
| **10** | `Status` | Enum | `Pending` (default), `Approved`, `Rejected` |

## 4. Configuration & Deployment

### Script Properties
Go to **Project Settings > Script Properties** in your Google Apps Script project and set:

| Property Key | Value Description |
|---|---|
| `GEMINI_API_KEY` | Google AI Studio Gemini API Key |
| `DRIVE_FOLDER_ID` | Google Drive folder ID where uploaded headshots will be stored |
| `CHAT_WEBHOOK_URL` | *(Optional)* Google Chat space incoming webhook URL |
| `SPREADSHEET_ID` | *(Optional)* Target Spreadsheet ID if script is standalone |

### Deploying the Web App
1. Click **Deploy > New deployment** in Google Apps Script.
2. Select type: **Web app**.
3. Set **Execute as:** `Me`.
4. Set **Who has access:** `Anyone`.
5. Click **Deploy** and copy the generated Web App URL.

### Web App Routing URLs
* **Public Intake Form:** `https://script.google.com/macros/s/.../exec?page=form`
* **Admin Dashboard:** `https://script.google.com/macros/s/.../exec?page=admin`
* **Wall of Love:** `https://script.google.com/macros/s/.../exec?page=wall`

### Embedding the Wall of Love
Paste this snippet on your sales page or site:
```html
<iframe 
  src="https://script.google.com/macros/s/.../exec?page=wall" 
  width="100%" 
  height="850" 
  frameborder="0" 
  style="border:none; border-radius:12px; width:100%;">
</iframe>
```
